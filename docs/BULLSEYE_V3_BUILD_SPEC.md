# Bullseye Theory V3 — Build Specification

## Objective
Replace the previous layered/overlay approach with one coherent landing-page architecture. The page should feel like a premium trading-education brand from the first viewport and remain fast, legible and simple.

## Page
1. Minimal sticky navigation
2. Cinematic hero
   - Huge typography
   - Bull/target focal visual
   - Animated market particles
   - Chart line and HUD labels
   - Primary CTA: Enter Student Area
   - Secondary CTA: Explore Curriculum
3. Method section
   - Study → Practice → Review
   - animated process rail
4. Curriculum
   - 11 numbered lessons
   - premium cards
   - horizontal/stacked responsive behavior
5. Learning experience
   - PDF + recorded video + chart practice visual treatment
6. Principles
   - Context before conclusions
   - Risk before reward
   - Process over impulse
7. Pricing CTA
   - ₹999
   - educational framing only
8. FAQ
9. Disclaimer/footer

## Motion
- Scroll reveal with blur-to-sharp
- Cursor spotlight on desktop
- Target rotation
- Chart draw animation
- Floating HUD labels
- Section transitions
- Card hover tilt on desktop only
- Reduced-motion fallback

## Do not
- Do not preserve the old hero and place another hero over it.
- Do not add random gradients/glows everywhere.
- Do not use fake performance/ROI numbers.
- Do not imply financial advice or guaranteed outcomes.
