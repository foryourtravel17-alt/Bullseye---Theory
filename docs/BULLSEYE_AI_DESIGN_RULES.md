# Bullseye Theory — AI Design Build Rules

## Design references used
- Anthropic Frontend Design: distinctive, intentional, production-grade visual direction; avoid generic AI aesthetics.
- UI/UX Pro Max: design-system-first workflow, responsive UX, accessibility, typography, motion, chart and stack guidance.
- Three.js r186: current stable WebGL foundation for the cinematic 3D hero.

## Bullseye visual system
- Obsidian background: #020304 / #0B0E14
- Signal lime: #A8FF61
- Metallic gold: #E4B957
- Off-white: #F4F5EF
- Institutional trading-terminal language; no easy-money, guaranteed-profit, or signal-selling framing.
- Hero must be an interface composition, not a poster.
- Desktop and mobile are art-directed separately; never simply scale the desktop composition down.

## Hero composition
1. Real 3D bull as the visual anchor.
2. Dubai/trading environment behind it.
3. Gold target/radar rings behind the bull.
4. Market ticker and quote cards as HUD layers.
5. Green candlestick telemetry at the edge.
6. Large editorial headline below/overlapping the visual anchor.
7. Bottom feature rail.
8. Subtle parallax and reduced-motion fallback.

## Engineering rules
- Keep GitHub private and never commit credentials.
- External assets must have a clear commercial-use license.
- Prefer CC0 assets for the hero prototype.
- Preserve existing course, auth, legal, privacy and disclaimer routes.
- Test narrow mobile widths before calling the hero complete.
