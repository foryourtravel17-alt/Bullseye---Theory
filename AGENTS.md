# Bullseye Theory — Agent Instructions

## Goal
Build Bullseye Theory as a premium, cinematic trading-education landing page. The priority is visual quality, motion, clarity, responsive behavior, and conversion—not dashboard complexity.

## Brand
- Background: obsidian #050709 / #020305
- Signal lime: #A8FF61
- Metallic gold: #E4B957
- Text: #F3F7F5
- Muted: #71877F
- Tone: institutional, precise, premium, educational.
- Never use easy-money claims, guaranteed returns, profit promises, signal-selling language, rockets, generic finance clip-art, or lifestyle-flex imagery.

## UX
- Mobile-first and desktop-responsive.
- Every section must remain understandable on a phone.
- Strong hierarchy: Hero → Method → Curriculum → Experience → Principles → Price/CTA → FAQ → Disclaimer.
- Keep navigation minimal.
- Motion must respect prefers-reduced-motion.

## Engineering
- Prefer vanilla HTML/CSS/JS unless the repository already requires a framework.
- Avoid unnecessary dependencies.
- Do not stack visual overlays over obsolete sections. Replace conflicting architecture cleanly.
- Keep auth.html, legal.html, privacy.html and disclaimer.html links functional.
- Test for horizontal overflow, broken anchors, missing assets and console errors.
- Use semantic HTML and accessible buttons/links.

## Visual direction
Think premium trading terminal + cinematic film title sequence + high-end finance landing page. Use SVG/CSS/canvas for charts, targets, grids and abstract market visuals. The bull is a brand focal point, not a gambling symbol.
