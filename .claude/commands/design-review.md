# Bullseye visual review

Use the live/local page and inspect it at 375px, 768px and 1440px.

Review in this order:
1. Hero focal hierarchy — the bull must remain the dominant visual.
2. Reference composition — Dubai atmosphere, gold target/radar, market UI and chart accents must read as one scene.
3. Typography — headline must remain dominant without covering the focal 3D asset.
4. Mobile art direction — no desktop scaling hacks, clipped cards or horizontal overflow.
5. Interaction — buttons, navigation, student login and anchors must work.
6. Accessibility — contrast, focus states, reduced motion and touch targets.
7. Console/network — no uncaught errors, missing assets or failed module imports.

Do not approve a visual change just because the source code looks clean; inspect the rendered result.
